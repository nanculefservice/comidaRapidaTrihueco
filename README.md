# 🍔 Trihueco Fast Food - Menú Digital & Landing Page

Una solución digital moderna para el negocio de comida rápida **Trihueco Fast Food**, ubicado en Los Álamos. El sitio funciona como una carta digital interactiva que facilita la visualización de productos y centraliza los pedidos a través de WhatsApp.

## 🚀 Sitio Web
Puedes ver el despliegue en vivo aquí:
**[https://nanculefservice.github.io/comidaRapidaTrihueco/](https://nanculefservice.github.io/comidaRapidaTrihueco/)**

## 🎯 Objetivo del Proyecto

Optimizar el proceso de venta del negocio local, permitiendo que los usuarios filtren productos por categorías y generen un pedido rápido sin necesidad de descargar aplicaciones pesadas o registrarse.

## 🚀 Características Principales

* **Menú Dinámico:** Sistema de filtrado por categorías (Completos, Fritos, Empanadas, Bebidas y Ofertas).
* **Call-to-Action (CTA) Directo:** Botón de pedido vía WhatsApp integrado en cada producto y en la sección de contacto.
* **Diseño "Mobile First":** Interfaz totalmente adaptativa (responsive) optimizada para smartphones.
* **Dark Mode Nativo:** Estética visual basada en tonos oscuros para resaltar la fotografía gastronómica.
* **Sección de Promociones:** Banner destacado para ofertas del día y combos especiales.

## 🛠️ Stack Tecnológico

* **Estructura:** HTML5 semántico.
* **Estilos:** CSS3 personalizado con variables para facilitar cambios de marca.
* **Interactividad:** JavaScript (Vanilla) para la lógica de filtros y manejo del DOM.
* **Hosting:** GitHub Pages.

## ⚙️ Instalación y Uso

1. Clona el repositorio:
```bash
git clone https://github.com/tu-usuario/trihueco-fastfood.git

```

2. Abre el archivo `index.html` en tu navegador.
3. Para modificar el número de WhatsApp, busca el enlace en el `index.html` y actualiza el parámetro `phone`.
